# Water Watcher

### Demo Script (for judges, 2 minutes)

1. Open the app on a phone. Show the home screen with “Report Water” and “View Map.”

2. Tap “Report Water.” Fill in: location (GPS auto), clarity “turbid,” smell “chemical,” upload a photo. Submit.

3. The report appears on the map as a red pin. Show the alert feed: “Water Safety Alert in [area].”

4. Turn off Wi-Fi. Submit another report. Show the “Offline – will sync” banner.

5. Turn Wi-Fi back on. Show the report syncing and appearing on the map.
